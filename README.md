# Immersive Escape Game – Computer History Museum (Prototype)
## Project overview
- **Type:** XR prototype / escape game
- **Purpose:** educational interactive experience
- **Audience:** general public (children, adults, elderly visitors)
- **Platform:** Unity – XR

Prototype of an immersive XR escape game designed for the **Museum of Informatics in Namur**.
The experience takes visitors through key periods of the history of computing, using interactive environments and **digital twins of historical computers**.

The goal was to create an engaging and accessible experience that combines **learning, exploration and problem-solving** for a wide audience.


### Context
This project was developed as part of an XR training program, within a team of six people, over a one-month timeframe.
Given the educational context and the limited duration, the focus was placed on:

- Rapid prototyping
- Experimentation
- Collaborative workflows
- Validating interaction concepts rather than final visual polish

As a result, some elements remain unfinished or unrefined, which is inherent to the scope and objectives of the project.

### Key features
- Immersive escape game mechanics
- Exploration of different computing eras
- Interactive digital twins of historical machines
- Adapted interaction design for a wide range of users

The project was developed with a strong focus on usability, accessibility and clarity of interactions, ensuring that visitors with different ages and technical familiarity can enjoy the experience.
